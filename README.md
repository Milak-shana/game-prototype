## 📖 About the Project

**The 13th Door** is a psychological mystery and puzzle-adventure game concept.

The player takes the role of **Alex**, who wakes up inside an unfamiliar abandoned mansion with no memory of how they arrived there.

Inside the mansion are twelve mysterious doors. Each door is connected to a forgotten memory from Alex's past.

The player must explore environments, investigate objects, collect clues and solve puzzles to uncover the truth behind Alex's forgotten memories.

The central mystery is connected to Alex's younger sister, **Mira**, and a forgotten childhood incident.

## 🎯 Week 2 Prototype

This project was created as part of **Week 2 – Gameplay Mechanics & Prototype Design**.

The prototype focuses on:

### 🚪 Door 01 – Childhood Bedroom

The player explores a mysterious childhood bedroom and interacts with different objects to discover clues.

The main objective is to solve a photograph-order puzzle and obtain a brass key.

---

## 🕹️ Gameplay Mechanics

The prototype demonstrates the following mechanics:

### 🔍 Exploration
Players explore the mansion hallway, childhood bedroom and other available locations.

### 🧩 Object Interaction
Players can examine important objects and discover information.

### 📜 Clue Collection
Important clues are collected during exploration.

### 🧠 Puzzle Solving
Players solve a chronological photograph arrangement puzzle.

### 🎒 Inventory System
Collected items are tracked in the inventory.

### 📖 Memory Journal
Important discoveries and clues are recorded in a memory journal.

### 🔐 Progression System
The player must complete the puzzle and obtain the brass key before progressing.

---

## 🧩 Main Puzzle

The player discovers three childhood photographs:

1. 🎂 Birthday
2. 🌳 Garden
3. 🌧️ Rain

The correct chronological order is:

**Birthday → Garden → Rain**

After solving the puzzle:

✅ The keepsake box unlocks  
🔑 The Brass Key 01 is revealed  
🚪 The player can unlock Door 01
